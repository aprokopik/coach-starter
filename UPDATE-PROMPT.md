# Update prompt: bring your coach up to the latest version

When the kit's makers tell you a new version is out, open `UPDATE-PROMPT.md` in the **coach-starter** repository (your own copy may be older or not have it), start a new session at claude.ai/code with your coach repository selected, copy everything below the line, and send it. Your profile, plans, log and data are never touched; only the coach's own engine, tools, dashboard and guides are swapped for the newer ones. It takes about 10 minutes.

---

Update my Coach to the latest starter kit. My repository is the one attached to this session. Work step by step, tell me each result in one line, and if a step fails, say so plainly, keep going where it is safe, and list what is still to do at the end. Never edit my personal files (`coach/athlete/`, `coach/CURRENT-STATE.md`, `coach/LOG.md`, plans, races, `data/`) except where a step below says so, and never send my health data anywhere.

1. **Get the newer kit.** Read `setup/kit.json` for the kit's home repository (`feedback_repo`); if there is no such file (kits before 4.3.0), ask me which repository I made my coach from (the `coach-starter` repository I was invited to). Attach it to this session (add it as a repository; I was invited to it) and clone it into a folder outside my repository, for example `/tmp/coach-kit`. If you cannot reach it, tell me, and ask me to download it from GitHub (Code, Download ZIP) and send it here, or to ask the person who invited me. If my repository has no `setup/update.py` (kits before 5.1.0), copy `setup/update.py`, `setup/personalize.py` and `setup/kit-manifest.json` from the newer kit into my `setup/` first.
2. **Look before changing.** Run `python3 setup/update.py /tmp/coach-kit`. Tell me, in plain words and briefly: the version I am on and the one I am moving to, what is new for me (from its WHAT'S NEW part, skipping anything that does not apply to my setup), and any file it would keep because it was edited here. Ask me to confirm before going on.
3. **Update.** Run `python3 setup/update.py /tmp/coach-kit --apply`. If it lists files in `setup/update-incoming/`, merge each into my copy by hand (keep my local changes, take the kit's fixes), show me the result in one line per file, then delete `setup/update-incoming/`. If it printed "Added section", tell me what it is in one sentence.
4. **Check.** Run `python3 -m unittest discover -s coach/tests`, then `python3 coach/tools/reconcile.py`, `python3 coach/tools/morning_facts.py` and `python3 coach/tools/build_dashboard.py`. All must finish without errors.
5. **Dashboard.** Load the updated page files into my dashboard (its link is in `setup/answers.json`, `links.dashboard_url`) as `coach/dashboard/MAINTAIN.md` ("Publishing") describes: `python3 coach/tools/pack_dashboard.py <dir>`, then write each `files/<name>` document. Open it at phone width and check it shows my name and events with no console errors. If the Race Season page link exists (`links.season_url`), publish `coach/dashboard/season.html` to it again.
6. **Morning task.** Open my scheduled tasks. If the morning check-in's prompt is a long pasted text rather than one line that points to `coach/ops/TASK-PROMPT-morning.md`, tell me to replace its prompt with this one line, so later updates reach it without another edit: "Attach the repository <my owner>/<my repository>, read coach/ops/TASK-PROMPT-morning.md and follow the text below its line." (with my repository's real owner and name filled in) (If you can edit the task yourself, do it and tell me.)
7. **Save.** Commit everything with the message "Update Coach to <new version>" and push to my default branch.
8. **Log it.** Add a line under "After setup" in `setup/SETUP-LOG.md`: the date, "Updated <old> to <new>", minutes taken, and anything that went wrong or was unclear. Ask me whether to send kit feedback now (`python3 setup/feedback.py`, as in `CLAUDE.md`). Commit and push.
9. **Finish.** One closing message: the version I am on now, the two or three changes that matter for me, anything not done, and anything I need to do (for example the morning task edit).
